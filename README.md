## 📖 Executive Overview

**ShopEase Pro** bridges consumer trust and cutting-edge retail technology. Built with **React 19, Tailwind CSS, Node.js, Express, and MongoDB**, it combines the high-throughput operational scale of Amazon and Flipkart with modern FinTech innovations:

* **💳 Digital Wallet & Instant FinTech Checkout:** Real virtual wallet balance starting at ₹0 for new accounts (₹1,500 demo float), 5% ShopEase Coin cashback, dynamic UPI QR code generator with countdown timer, "ShopEase Pay Later" (BNPL with ₹25,000 credit limit), and 0% No-Cost EMI comparison calculator.
* **🔄 Automated Doorstep Returns & Instant Wallet Refunds:** Complete reverse-logistics pipeline where customers schedule pickups and admin approvals automatically disburse refund cash directly to the customer's Virtual Wallet.
* **🤖 "ShopBot" AI Shopping Assistant & Live Support Desk:** Floating natural language assistant recommending verified catalog products with 1-click cart insertion, paired with an integrated customer support ticketing help desk.
* **🛡️ Zero-Dark-Pattern Transparency:** Honest 8% seller margins, ₹0 hidden convenience fees, and 100% plastic-free packaging disclosure on every product card.
* **⚡ 100% Offline / Static Vercel Resilience:** Full client-side `localStorage` mirroring ensuring every cart action, wallet top-up, price drop claim, and order placement works seamlessly even without an active backend server.

## 🌟 Key Features & Innovations

### 1. 📈 30-Day SVG Price History & Fake-Discount Detector
Unlike traditional e-commerce giants that artificially inflate MRPs to fabricate artificial "80% OFF" sales:
* **Interactive 30-Day SVG Price Curve:** Hover over dynamic date nodes to inspect genuine historical price fluctuations.
* **Fake Discount Detection Meter:** Algorithmic badge categorizing whether the current price is the *"Lowest Price in 30 Days"* or *"Fair Market Average"*.
* **SmartSense™ 48-Hour Price Lock:** Freeze promotional flash-deal prices for 48 hours without paying upfront, shielding buyers from price surges until payday.

### 2. 🛡️ Instant 7-Day Price-Drop Protection Guarantee
* If the price of any purchased product drops within 7 days of delivery, ShopEase Pro calculates the difference and provides a **1-Click Auto-Refund** directly into the customer's **ShopEase Virtual Wallet**, accompanied by a simulated SMS and WhatsApp alert.

### 3. 🌿 One-Click Eco-Checkout Option (+50 Loyalty Coins)
* A dedicated sustainability toggle at checkout: *"Consolidate items into 1 Box / Plastic-Free 100% Recycled Packaging"*.
* Selecting eco-packaging instantly credits the buyer with **+50 Loyalty ShopEase Coins** for supporting green logistics.

### 4. 🤖 "ShopBot" AI Shopping Assistant & Live Help Desk
* **Natural Language Product Discovery:** Ask questions like *"What is the best gaming laptop under ₹70,000?"* or *"Do you have wireless headphones with active noise cancellation?"* and ShopBot immediately parses catalog metadata, specs, and price ranges to suggest clickable product cards with direct "Add to Cart" triggers.
* **Ticketing Help Desk:** If AI cannot resolve an issue, customers can open support tickets with priority levels, which admins inspect and resolve with instant reply threads from Seller Central.

### 5. 👥 "Squad Buy" Viral Group Buying (Save 15%)
* Inspired by Pinduoduo's viral commerce model: launch a 2-person buying squad with a 24-hour expiration window.
* Generates unique shareable links (`shopease.pro/squad/SQD-XXXX`) with simulated friend participation that instantly unlocks a **flat 15% discount** for both buyers.

### 6. 🎁 CRED-Style Mystery Scratch Cards & Gift Cards
* **Post-Checkout Scratch Card:** Every completed order rewards the buyer with a metallic holographic scratch card with real cursor foil scraping, confetti burst, and automatic deposit of **+₹150 Cash** and **+100 Coins** into the Virtual Wallet.
* **Digital Gift Cards:** Purchase and send branded vouchers across 4 themes (*Tech Geek, Birthday Surprise, Festive Celebration, VIP Reward*) with instant voucher code redemption into any wallet.

### 7. 💳 "ShopEase Pay Later" (BNPL) & 0% No-Cost EMI
* **Pre-Approved BNPL Credit Line:** ₹25,000 credit limit with 30-day interest-free repayment terms and 1-click checkout.
* **0% No-Cost EMI Comparison Calculator:** Side-by-side tenure breakdowns (3, 6, 9, 12 months) across major banking partners (HDFC, ICICI, Axis, SBI).

### 8. 📸 AI "Snap & Search" Visual Image Search
* Upload or select gadget images to trigger computer-vision style catalog matching with simulated feature vector scanning, percentage confidence score, and direct navigation.

### 9. 📦 "Subscribe & Save 10%"
* Automated replenishment engine for daily essentials and computer accessories. Choose delivery intervals (30, 60, or 90 days) with a guaranteed **10% recurring discount** managed from the User Account Hub.

### 10. 📡 Live Shopper Radar & Abandoned Cart Recovery (Admin)
* Seller Central radar actively monitors in-progress carts, tracks at-risk GMV, and empowers sellers to dispatch automated **WhatsApp & SMS recovery nudges** containing single-use 5% discount vouchers (`RECOVER5`).

### 11. 🌍 Multi-Currency Global Localization
* Dynamic currency toggle in the navbar seamlessly translates all catalog prices, cart totals, and wallet balances between **INR (₹)**, **USD ($)**, **EUR (€)**, and **GBP (£)** with live exchange rate math.

| Layer | Technologies | Key Responsibilities |
| :--- | :--- | :--- |
| **Frontend UI** | **React 19, Tailwind CSS v4, Lucide Icons, Canvas-Confetti** | Responsive storefront, animated modals, slide-over drawers, SVG charts, and holographic card shaders. |
| **State Management** | **React Context API (Auth, Cart, Wallet, Currency, Notification)** | Centralized reactive state with multi-tab synchronicity and zero external Redux bloat. |
| **Resilience Engine** | **Smart Hybrid `apiClient.js`** | Intercepts HTTP requests and falls back to browser `localStorage` if backend is unreachable (100% interactive on static Vercel deployments). |
| **Backend API** | **Node.js, Express.js** | Secure RESTful endpoints with JWT bearer authentication, role-based access control, and payload sanitation. |
| **Database** | **MongoDB, Mongoose ORM, MongoMemoryServer** | Relational schemas for Users, Products, Orders, Wallets, Returns, Tickets, BNPL, Subscriptions, and Squads. Automatically falls back to in-memory MongoDB if standalone mongod is offline. |

## ⚡ Quick Start & Local Setup

### Prerequisites
* **Node.js** (v18.0.0 or higher)
* **npm** (v9.0.0 or higher)

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/shopease-pro.git
cd shopease-pro
```

### 2. Backend Setup & Seeding
```bash
# Navigate to backend directory
cd backend

# Install dependencies
npm install

# Seed the database with 13 products, demo accounts, orders, returns, and tickets
npm run seed

# Start the Express API server (runs on http://localhost:5000)
npm start
```
> **Note:** The backend automatically boots an internal in-memory MongoDB instance (`MongoMemoryServer`) if a local MongoDB service (`mongodb://127.0.0.1:27017`) is not running.

### 3. Frontend Development Server
Open a new terminal window:
```bash
# Navigate to frontend directory
cd frontend

# Install dependencies
npm install

# Start Vite development server with Hot Module Replacement
npm run dev
```

Visit **[http://localhost:5173/](http://localhost:5173/)** in your browser.

### 4. Build for Production
To verify zero syntax, linting, or module resolution errors:
```bash
cd frontend
npm run build
```
